# Four Card Feature Section

Responsive feature section layout built with semantic HTML and CSS.

## Stack

- HTML5
- CSS Grid (page layout)
- Flexbox (card internal layout)
- CSS custom properties

## Notes

- Mobile-first implementation
- Layout capped with `max-width` to prevent excessive scaling on large screens
- Headings use `clamp()` for fluid scaling; body text remains fixed for readability
